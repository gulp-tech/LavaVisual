# LavaVisual 2.2 — Minecraft 26.2

**[Скачать lavavisual-2.2.0-mc26.2.jar](artifacts/lavavisual-2.2.0-mc26.2.jar)**

Клиентский HUD и косметика. Тёмное меню с Inter, анимированными вкладками и
переключателями; общий RGB-цвет настраивается прямо в интерфейсе.

## Установка

Удалите прежний JAR LavaVisual из `mods`, установите новый. Требуются Minecraft
**26.2**, Fabric Loader **0.19.3+**, Fabric API **0.161.0+26.2** и Java **25+**.

Все модули **изначально выключены**. При первом переходе с 2.0/2.1 переключатели
однократно выключаются; расположение HUD сохраняется. Удалённые панели и старые
цветовые пресеты больше не используются. В дальнейшем ручной выбор сохраняется.

## Меню и управление

**Right Shift** — меню. **V** — выключить все модули. Колёсико мыши прокручивает
длинные страницы; ползунки работают перетаскиванием, запись на диск — после отпускания.

| Вкладка | Возможности |
| --- | --- |
| HUD | Координаты, FPS, Target HUD с аватаром игрока. Стрелка справа — размер и плотность фона; редактор — перетаскивание. |
| Эффекты | Пользовательский прицел; Jump Circle при своём прыжке; искры ручной атаки; декоративная звёздная пыль. |
| Руки | Независимые X, Y, Z и масштаб основной/второй руки от первого лица. |
| Звуки | По два варианта ударов, критов и тотема; отдельные громкости и кнопки «Слушать». |
| RGB / UI | Каналы R/G/B 0–255, мгновенный образец цвета, тени, анимации и выключение всех модулей. |

Секундомер, его горячая клавиша и уведомления **удалены полностью**. Вместо
разрозненных цветовых настроек используется единый RGB-цвет меню, HUD и эффектов.
Редактор показывает демонстрационные панели даже для выключенных модулей — это
не включает их в игре. Прицел остаётся ванильным, пока не включён пользовательский.

### Руки

X/Y: −1…1; Z: −0.5…1.5; масштаб: 0.4…1.8. Положительный Z отдаляет
руку/предмет от камеры. Это **только преобразование изображения**, не дальность
атаки, не хитбоксы и не изменение взаимодействий. Карта, удерживаемая двумя руками,
использует общую ванильную отрисовку основной руки.

### Косметические эффекты

- Расширяющееся двойное кольцо на месте собственного прыжка, радиус 0.5–2.
- Светящиеся искры при ручном ударе по видимой живой цели под ванильным прицелом;
  это эффект нажатия атаки, **не подтверждение урона сервером**.
- Звёздная пыль — случайные декоративные огоньки вокруг своего игрока, не метки сущностей.
- Проверка глубины как у ванильной геометрии, без записи глубины и без видимости
  сквозь непрозрачные блоки. Нет ESP, Chams, трассеров и перебора сущностей мира.
- До 4 колец и 96 искр одновременно; ограниченное время жизни, очистка при смене мира.
  В отрисовку передаются снимки без ссылок на сущности/мир. Эффекты — интерпретация
  референса, не копия чужого логотипа или интерфейса SOUP VISUALS.

### Звуки и лицензии

Встроены шесть эффектов из коллекции **Kenney (CC0)**: мягкий/тяжёлый удар,
металл/аркада для крита, колокольчик/Power Up для тотема. Это выбранные игровые
эффекты из известной коллекции, а не утверждение о рейтинге популярности.
Заменяются соответствующие ванильные события, в том числе слышимые события других
игроков; сохраняются их позиция, категория звука, высота тона и затухание по расстоянию.
Громкость каждого типа 0–100%, дополнительно действуют ванильные регуляторы.
Предпрослушивание доступно и при выключенном модуле. Все OGG — моно, 44.1 кГц.

Шрифт **Inter — SIL OFL 1.1**, действует только внутри LavaVisual. Лицензии,
исходные URL и SHA-256 оригиналов/конвертированных звуков: `licenses/`, также в JAR.

## Target HUD и серверные ограничения

Показывает имя, аватар игрока (для мобов — значок LV), HP/max HP, броню и расстояние
только для текущей живой цели под ванильным прицелом. Нужны прямая видимость и
дистанция не больше 6 блоков. Собственный игрок, невидимые и наблюдатели исключены.
При потере цели данные сбрасываются на следующем клиентском тике; поиска или
запоминания игроков нет. В редакторе явно показаны демонстрационные данные.

Сервер может не передавать реальное здоровье других игроков: точность удалённого
HP не гарантируется. Скрытые данные не восстанавливаются. Автоматизации атак,
инвентаря и применения предметов нет. **Даже косметика и Target HUD могут требовать
отдельного разрешения администрации сервера** — отсутствие ESP не равно одобрению.

## Настройки, сборка и проверки

Настройки: `config/lavavisual-hud/hud.json`. Для полного сброса закройте игру и
удалите этот файл. Положение HUD нормализовано относительно размера экрана.

С JDK 25: `./gradlew build` из корня или `ports/mc26.2`; Windows: `gradlew.bat build`.
Артефакт находится в `build/libs/` соответствующего проекта. Звуки уже сконвертированы,
FFmpeg для обычной сборки не требуется.

CI выполняет сборку, тесты конфигурации/миграции/границ, проверку состава JAR и
запуск клиента с Loader 0.19.3 под Xvfb. Проверка интерфейса открывает все пять
вкладок, настройки Target HUD/прицела и редактор. Это **не проверка игрового мира**:
визуальную корректность колец, искр, рук, аватаров и звуков в реальной игре, а также
совместимость с шейдерами нужно проверять отдельно. Улучшение FPS не обещается.
