# LavaVisual — Minecraft 26.2

Текущая поставка — **один самостоятельный мод только для Minecraft 26.2**.
Никаких вложенных адаптеров 1.20.4/1.21.4 и мода `lavavisual_bundle`.

## Установка

1. Удалите **все предыдущие JAR LavaVisual** из папки `mods`, особенно
   `lavavisual-1.1.0-multiversion.jar` и отдельные старые адаптеры.
2. Установите Fabric Loader **0.19.3 или новее** для Minecraft **26.2**.
3. Используйте **Java 25+** и Fabric API **0.161.0+26.2**.
4. Скачайте **[lavavisual-1.1.1-mc26.2.jar](artifacts/lavavisual-1.1.1-mc26.2.jar)**
   (на GitHub — кнопка Download raw file) и поместите его в `mods`.

На сервер мод ставить не нужно. Fabric API в JAR не включён.
Версии игры, отличные от 26.2, этот файл намеренно не поддерживает.

## Управление

| Клавиша | Действие |
|---|---|
| V | Включить/выключить все визуалы |
| B | ESP: 3D → 2D → выключен |
| J | Трассеры |
| K | Chams |

Переназначение: Настройки → Управление → LavaVisual.
Визуалы включены по умолчанию. Изменения сохраняются сразу.

## Функции

- 3D-рамки с градиентом `#8B0000 → #FF0000 → #FF6B00`.
- Плоские вертикальные 2D-рамки, поворачивающиеся к камере по yaw.
- Трассеры с интерполяцией позиции и учётом расстояния.
- Дополнительный полупрозрачный проход анимированных моделей без проверки
  глубины и без записи в depth buffer (Chams).
- Фильтры игроков/мобов, ограничение дистанции и числа целей.

Рендеринг 26.2 использует LevelExtractionEvents, снимки состояния кадра,
SubmitNodeCollector и собственные GPU RenderPipeline/RenderType.

## Настройки

Файл `.minecraft/config/lavavisual.json`. Для ручного редактирования закройте
игру: файл читается при запуске.

```json
{
  "enabled": true,
  "boxMode": "BOX_3D",
  "tracers": true,
  "chams": true,
  "players": true,
  "mobs": true,
  "maxDistance": 96.0,
  "maxEntities": 128,
  "chamsAlpha": 0.38
}
```

`boxMode`: `OFF`, `BOX_3D`, `BOX_2D`. Дистанция ограничена 8–256 блоками,
число целей — 1–512, прозрачность Chams — 0.05–0.85. Исключены собственный
игрок, камера, мёртвые/невидимые сущности и наблюдатели. При достижении лимита
выбираются первые подходящие сущности, не обязательно ближайшие.

## Сборка и проверки

Из корня репозитория с JDK 25:

```bash
cd ports/mc26.2
./gradlew build
```

Windows: `gradlew.bat build`. Основной файл:
`ports/mc26.2/build/libs/lavavisual-1.1.1-mc26.2.jar`.
`*-sources.jar` не предназначен для установки.

Workflow `.github/workflows/mc26.2.yml` собирает мод, запускает тесты палитры,
проверяет самостоятельный манифест и запускает клиент Minecraft 26.2 с
**Fabric Loader 0.19.3** под Xvfb. Публикация JAR выполняется только после
успешных проверок. Происхождение сборки — `artifacts/STANDALONE-26.2.txt`,
контрольные суммы — `artifacts/SHA256SUMS`.

Проверка запуска подтверждает инициализацию мода, миксинов и ресурсов, но
**не заходит в мир**. Внешний вид ESP/Chams, разные GPU и FPS требуют
отдельной игровой проверки. Sodium, Iris, шейдерпаки и Fabulous не проверены.
Chams наследует отсечение моделей игрой и отдельно не перекрашивает броню,
предметы в руках или дополнительные feature-renderer слои.

## Почему изменена поставка

Предыдущий bundle требовал Loader 0.19.5, тогда как на предоставленном
скриншоте установлен 0.19.3. Новая сборка проверяется непосредственно на
0.19.3 и содержит только реализацию 26.2, без выбора между адаптерами.

Исходники и старые артефакты других версий сохранены в репозитории как архив.
Мультиверсионный workflow больше не запускается автоматически. Для текущей
установки используйте только файл **1.1.1-mc26.2**.
