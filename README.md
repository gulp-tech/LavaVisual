# LavaVisual HUD 2.0 — Minecraft 26.2

Новая локальная HUD-версия. **ESP, Chams, трассеры и миксины рендера сущностей удалены**
из исходников текущей ветки и нового JAR. Автоклики, tap-fire, изменение хитбоксов,
сканирование мира и сетевые игровые действия отсутствуют.

## Установка

Удалите все старые JAR LavaVisual, особенно 1.x и multiversion. Установите
`lavavisual-2.0.0-mc26.2.jar`, Fabric API **0.161.0+26.2**, Fabric Loader
**0.19.3+**, Java **25+**, Minecraft **26.2**.

## Что реализовано

- **Right Shift** — ClickGUI: включение/скрытие панелей, шесть цветов, темы Dark/Glass,
  тени, анимация интерфейса мода, выбор косметического прицела.
- **Drag HUD elements** — редактор: перетаскивание панелей мышью, сохранение
  относительного положения при изменении разрешения, скрытие и перекраска.
- Панели: собственные координаты, FPS, длительность сессии, секундомер, Java heap,
  Dynamic Island с локальными уведомлениями (подключение, секундомер, профили).
- **F8** — старт/пауза секундомера; сброс через GUI. Это реальное время, не серверные тики.
- **V** — включение/выключение HUD. Клавиши можно переназначить в управлении.
- Три слота профилей. Список друзей (до 64 имён) — локальная записная книжка,
  **без поиска, слежения, подсветки, автоатак и изменений поведения PvP**.
- Прицел: vanilla, точка, плюс, квадрат; цвет меняется отдельно. По умолчанию vanilla.
- Настройки: `config/lavavisual-hud/hud.json`; профили рядом. Старый
  `config/lavavisual.json` не читается, старые ESP-настройки не переносятся.

## Границы этой версии

Это **не полная реализация всего присланного списка**. Не добавлены:
- Target HUD с чужим HP, Damage Numbers, Hitbox Helpers и Trajectory Prediction:
  без разрешения администрации они могут подпадать под запрет преимуществ в PvP.
- tap-fire и прочая автоматизация: исключены по предоставленным правилам.
- HD-скины/текстуры, анимации ванильного чата/tab/перспективы/хотбара,
  Block Overlay, Hit Particles и Critical Hit Effect: в этой версии не реализованы.
- FPS Boost/Chunk Optimizer: нет ложных обещаний ускорения. HUD показывает реальные
  показатели; данные FPS/heap обновляются раз в секунду. Мод не меняет дальность
  прорисовки и не вызывает System.gc(). Heap monitor — **не memory optimizer**.

Нельзя гарантировать разрешённость даже косметического мода на конкретном сервере:
окончательное решение за администрацией. Прицел и координаты также согласуйте с ней.

## Сборка

С JDK 25: `./gradlew build` в корне либо в `ports/mc26.2`.
На Windows — `gradlew.bat build`. Артефакт в `build/libs/` соответствующего проекта.
CI проверяет конфигурацию и профили, отсутствие старых рендер-модулей в JAR,
запуск клиента с Loader 0.19.3. Запуск до меню не заменяет игровую проверку
перетаскивания, изменения разрешения и совместимости с другими модами.
