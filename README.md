# LavaVisual HUD 2.1 — Minecraft 26.2

**[Скачать lavavisual-2.1.0-mc26.2.jar](artifacts/lavavisual-2.1.0-mc26.2.jar)**

Новый компактный интерфейс: тёмные панели, оранжевая активная вкладка,
переключатели и отдельные настройки модулей. Название — LavaVisual.

## Установка и начальное состояние

Удалите старые JAR LavaVisual из `mods`. Нужны Minecraft **26.2**, Fabric Loader
**0.19.3+**, Fabric API **0.161.0+26.2**, Java **25+**.

**При первой установке все модули выключены.** После обновления с 2.0 старые
автоматически включённые панели также выключаются однократно. Положение и цвета
сохраняются. После этого выбранные вами переключатели сохраняются при перезапуске.
Новый HUD не появляется, пока вы сами не включите соответствующий модуль.

## Управление

- **Right Shift** — открыть меню.
- **HUD** — координаты, FPS, секундомер, уведомления, Target HUD.
- Нажатие на карточку/переключатель — включить или выключить модуль.
- **⋮ справа на карточке** — настройки цвета, размера, непрозрачности фона.
- **Редактор расположения** — перетаскивание панелей мышью. Он показывает
  предпросмотр даже выключенных панелей; это не включает их в игре.
- **Визуалы → Прицел → ⋮** — форма, цвет, размер и непрозрачность прицела.
- **Настройки** — тени, анимация меню, выключение всех модулей и сброс положения.
- **V** — выключить все модули (не скрытый общий переключатель).
- **F8** — запуск/пауза секундомера. Сброс — в настройках его карточки.

Прицел по умолчанию остаётся ванильным. Пользовательский прицел изначально выключен.
Уведомления не занимают экран в простое: панель появляется только при событии.
Постоянная надпись «Local HUD / no automation» удалена.

Из меню убраны список друзей, профили, монитор памяти, время сессии и лишние
кнопки. ESP, Chams, трассеров, сканирования мира и автоматизации действий нет.

## Target HUD

Выключен по умолчанию. Показывает имя, HP/max HP, броню и расстояние только у
живой сущности непосредственно под ванильным прицелом:

- без поиска ближайшего игрока и без списка сущностей;
- дополнительная проверка прямой видимости и дистанции не более 6 блоков;
- невидимые, мёртвые, собственный игрок и наблюдатели исключены;
- цель не запоминается: данные сбрасываются на следующем клиентском тике,
  если курсор ушёл с цели или она больше не видна;
- в редакторе HUD отображаются только явно обозначенные демонстрационные данные.

Значения здоровья берутся из доступных клиенту данных. Сервер может не передавать
актуальное здоровье других игроков — в таком случае HUD не может гарантировать
точное HP. Никакого восстановления скрытой информации или предсказания здоровья нет.

**Target HUD с чужим HP может быть запрещён правилами конкретного сервера.**
Согласуйте его с администрацией; отсутствие ESP не означает автоматического разрешения.

## Настройки и сборка

Файл: `config/lavavisual-hud/hud.json`. Для полного возврата к выключенным настройкам
закройте игру и удалите этот файл либо нажмите «Выключить все модули» в GUI.
Размер панелей: 60–160%; плотность фона: 20–100%. Прицел: размер 60–200%.
Положение сохраняется относительно доступной области экрана.

С JDK 25: `./gradlew build` из корня либо из `ports/mc26.2`.
Windows: `gradlew.bat build`. Артефакты в `build/libs/` соответствующего проекта.

CI проверяет выключенные начальные настройки, миграцию 2.0, сохранение ручного
выбора, допустимые размеры/цвета, сборку и запуск клиента с Loader 0.19.3.
Проверка интерфейса открывает вкладки меню, настройки Target HUD/прицела и редактор.
Это не заменяет проверку реальной цели в игровом мире или совместимости с шейдерами.
