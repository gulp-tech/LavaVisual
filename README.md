# LavaVisual

Клиентский Fabric-мод с лавовым ESP, трассерами и просвечивающими моделями.

## Совместимость

- **Minecraft Java Edition 1.20.4**, Java 17.
- Fabric Loader **0.15.11+** и Fabric API **0.97.2+1.20.4**.
- Fabric Loom 1.6.12, Yarn 1.20.4+build.3, Gradle Wrapper 8.6.
- На выделенный сервер мод устанавливать не нужно.

Minecraft 1.20.5+, 1.21.x и 26.x **не поддерживаются этой сборкой**. Для них
нужны отдельные порты и тестирование: меняются Java, модели, сигнатуры миксинов
и рендер-пайплайн. Манифест намеренно разрешает только 1.20.4.

## Возможности

- **3D ESP**: 12 рёбер bounding box с вертикальным градиентом
  `#8B0000 → #FF0000 → #FF6B00`. Вертикальные рёбра разбиты в средней точке,
  поэтому все три цвета представлены точно.
- **2D ESP**: вертикальная плоская рамка, поворачивающаяся к камере по yaw
  (billboard в мире, не прямоугольник экранного HUD).
- **Tracers**: линия от точки перед камерой до центра интерполированного бокса;
  цвет и прозрачность учитывают дистанцию. Позиции интерполируются по tick delta.
- **Chams**: дополнительный полупрозрачный лавовый проход **настоящей
  анимированной модели**, а не заливка её bounding box. Собственная белая текстура
  не меняет скины или ресурсы игры. Проход рисуется после мира без проверки
  глубины и без записи в depth buffer.
- Фильтры игроков/мобов, ограничение дистанции и числа целей, настройки в JSON.
- Отдельные RenderLayer, переиспользуемые буферы и пакетный draw для каждого
  прохода. OpenGL-состояние управляется фазами RenderLayer; общий буфер игры
  мод не сбрасывает.

## Клавиши

| Клавиша | Действие |
|---|---|
| **V** | Включить/выключить все визуалы |
| **B** | Переключить ESP: 3D → 2D → выключен |
| **J** | Включить/выключить трассеры |
| **K** | Включить/выключить Chams |

Клавиши переназначаются через **Настройки → Управление → LavaVisual**.
Стандартно визуалы включены. Изменения сохраняются сразу.

## Настройки

Файл `.minecraft/config/lavavisual.json` создаётся при первом запуске.
Для ручного редактирования закройте игру; настройки читаются при запуске.

```json
{
  "enabled": true,
  "boxMode": "BOX_3D",
  "tracers": true,
  "chams": true,
  "players": true,
  "mobs": true,
  "maxDistance": 96.0,
  "maxEntities": 128,
  "chamsAlpha": 0.38
}
```

`boxMode`: `OFF`, `BOX_3D`, `BOX_2D`. Дистанция ограничивается 8–256 блоками,
число целей — 1–512, прозрачность Chams — 0.05–0.85. Собственный игрок,
камера, мёртвые, невидимые сущности и наблюдатели исключаются. Мобы включают
дружественных животных. При достижении лимита выбираются первые подходящие
сущности в порядке обхода мира, не обязательно ближайшие.

## Сборка

Нужен установленный **JDK 17** и доступ к Maven Central, Fabric Maven,
серверам Minecraft и дистрибутиву Gradle.

```bash
./gradlew build
```

Windows:

```bat
gradlew.bat build
```

После успешной сборки:

- `build/libs/lavavisual-1.0.0+mc1.20.4.jar` — устанавливаемый remapped JAR;
- `build/libs/lavavisual-1.0.0+mc1.20.4-sources.jar` — исходники, не для установки.

`build` запускает JUnit-тесты палитры: контрольные цвета, границы и непрерывность
интерполяции. Для dev-клиента: `./gradlew runClient`.

Также подготовлен шаблон `docs/build-workflow.yml`: JDK 17, сборка и публикация
артефакта `LavaVisual-mc1.20.4`. Для отправки этого файла подключению GitHub
требуется разрешение **workflows**. Через сайт GitHub можно самостоятельно
создать `.github/workflows/build.yml` в ветке `arena/01a0d2b1-lavavisual`,
скопировав туда шаблон. После сохранения push запускает сборку автоматически.
Результат доступен в **Actions → Build LavaVisual → Artifacts**.

## Установка

1. Установите Fabric Loader для **Minecraft 1.20.4**.
2. Поместите Fabric API для 1.20.4 в `.minecraft/mods/`.
3. После сборки скопируйте туда основной JAR LavaVisual (без `-sources`).
4. Запустите профиль Fabric.

## Архитектура

- `LavaVisual` — общий entrypoint и логирование.
- `LavaVisualClient` — клавиши, фильтрация целей, WorldRenderEvents.
- `VisualConfig` — JSON, валидация и сохранение.
- `BoxEsp`, `Tracers`, `Chams` — независимые модули.
- `RenderUtils`, `LavaPalette`, `LavaRenderLayers` — геометрия, цвета и GPU-фазы.
- `LivingEntityRendererMixin` — дополнительная отправка геометрии основного
  EntityModel с уже рассчитанной анимацией; оригинальный вызов сохраняется.

## Ограничения и проверка в игре

Chams наследует frustum/distance culling оригинального рендера сущностей:
мод не заставляет игру рисовать модели, которые она вообще не отправляет на
рендеринг. Броня, предметы в руках и feature-renderer слои отдельно не
перекрашиваются. Совместимость с Sodium, Iris, шейдерами и другими модами,
меняющими LivingEntityRenderer, не проверена; Redirect может конфликтовать
с аналогичными миксинами. Гарантии FPS без игрового профилирования нет.

Перед использованием проверьте в чистом Fabric-клиенте:

- рамки, трассеры и Chams у игрока и мобов за непрозрачной стеной;
- движение между тиками, от первого и третьего лица;
- градиент, режимы 3D/2D и ограничение дистанции;
- отключение V, J, K, сохранение после перезапуска;
- обычный рендер мира/руки/HUD после выключения визуалов;
- смену мира, измерения и переподключение;
- Fast/Fancy/Fabulous; затем отдельно сторонние рендер-моды.

Используйте на своём мире или там, где правила сервера разрешают такие визуалы.

## Статус проверки текущей реализации

Исходники и Wrapper подготовлены. **Успешная компиляция и игровой запуск пока
не подтверждены; готовый JAR не получен.** В среде создания отсутствует Java,
загрузка JDK/зависимостей завершается сетевой ошибкой, а отправка workflow
отклонена GitHub из-за отсутствия права `workflows`. Это ограничение сборочной
среды, но до настоящего запуска компилятора нельзя исключить ошибки кода.
